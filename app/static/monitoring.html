How the live forecasts are doing

Every forecast the model issues is logged. Once the Kp for its 3-hour interval has been observed, it is scored the same way as in the offline evaluation: Brier score, and skill against persistence (Kp stays as it is) and climatology (the long-term base rate).

Skill so far

Skill above 0 means better than the reference. With few storms the Kp ≥ 5 scores are noisy. Observed Kp is the GFZ nowcast, not yet the definitive value, so all scores are provisional.
